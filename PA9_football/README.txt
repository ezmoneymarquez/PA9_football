Game Description and Instructions:
This game is a simple version of a 2D American Football game where a play runs continuously and restarts
when the play ends in a tackle, incomplete pass, or touchdown. The game includes snapping the ball, passing,
catching, and defensive pursuit. A player can control the quarterback and either run after the snap or pass to a receiverl.

The quarterback can move using keys W,A,S, and D. Pressing C will snap the ball and start the play, and then pressing E
will allow the quarterback to throw the ball to the nearest receiver.
After the first play, the game will enter an endless loop where the defenders will constantly chase the ballcarrier until
the ballcarrier either scores a touchdown by entering the endzone or the defender tackles (makes contact with) them.

If the play result ends with either an incomplete pass or touchdown, the program will write to the console either
"INCOMPLETE PASS" or "TOUCHDOWN", respectively, to keep track of the flow of the game.
